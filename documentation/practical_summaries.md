# Practical Project Summaries & Curricular Overview

This document summarizes the learning outcomes, core components, and educational value of each practical project.

---

### Practical 03: UI Design
- **Objective**: Construct responsive Android user interfaces using `ConstraintLayout`, `TextView`, `EditText`, `Button`, `ImageView`, and custom XML drawables.

### Practical 04: Explicit Intent Navigation
- **Objective**: Inter-activity communication, passing primitive and structured intent extras, and managing the activity back stack.

### Practical 05: Background Computation with ExecutorService
- **Objective**: Offloading CPU-intensive mathematical tasks (primality tests) from the Main/UI thread to background worker threads.

### Practical 06: Android Notifications
- **Objective**: Designing high-priority notifications with Notification Channels, small icons, and PendingIntent action callbacks.

### Practical 07: Custom BroadcastReceiver
- **Objective**: Creating a publish-subscribe broadcast messaging model inside an application.

### Practical 08: Location Awareness, Sensors & Native Hardware Access
- **Objective**: Interacting with real-world physical device peripherals: acquiring geographic coordinates via `LocationManager` (GPS/Network), streaming 3-axis motion acceleration data via `SensorManager` (Accelerometer), triggering haptic feedback via `Vibrator`, toggling the rear LED torch via `CameraManager`, and querying battery charge state via `BatteryManager`.
- **Key Takeaway**: Understanding hardware subsystem managers, dangerous runtime permissions (`ACCESS_FINE_LOCATION`), sensor sampling rates, and battery-saving lifecycle management (`onResume`/`onPause`).

### Practical 09: Android Started Service
- **Objective**: Implementing background execution components without user interfaces and monitoring lifecycle transitions.

### Practical 10: Phone Contacts ContentProvider
- **Objective**: Accessing system databases via `ContentResolver` to query phonebook contacts.

### Practical 11: Dynamic Views Generation
- **Objective**: Instantiating and configuring Android views dynamically in Java at runtime.

### Practical 12: Enterprise REST API Access
- **Objective**: Communicating with remote cloud servers over HTTPS and parsing JSON payloads.

### Practical 13: Graphics and Custom Views Using Canvas
- **Objective**: Creating custom Android view components and drawing 2D graphics directly onto a Canvas.

### Practical 14: Animation and Multimedia (Audio Playback)
- **Objective**: Integrating media playback (`MediaPlayer`) with continuous property animations (`ObjectAnimator`).
